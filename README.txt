# 費用一覧アプリ vol.2

## vol.2の追加機能
- タイトル横にアプリアイコンを表示
- 画面下部にバージョン表記（vol.2）
- 一覧に表示中データの合計額（円換算）を表示
- JPY / USD / KRW / EUR / GBP / TWD / THB / AUD / CAD / CNY / SGD / HKDに対応
- 外貨入力時は「1通貨あたりの円換算レート」を入力。例：1 KRW = 0.11円
- 費用精算タブで支出ごとに精算除外を選択
- 2人または3人で均等精算し、誰から誰へいくら支払うかを表示
- CSV・JSONバックアップに通貨、換算レート、精算除外情報を追加

## ファイル
- index.html: アプリ本体
- manifest.webmanifest: ホーム画面追加用設定
- sw.js: オフライン表示
- icon.svg: アプリアイコン

## 公開方法（GitHub Pagesの例）
1. ZIPを展開し、中のファイルをGitHubリポジトリ直下にアップロード（既存ファイルは上書き）。
2. GitHub Pagesの公開設定は既存のままでOK。
3. iPhoneのSafariでアプリを再読み込み。ホーム画面追加済みの場合は、Safari側で一度サイトを開いて更新後に起動してください。

## データについて
- IndexedDBのデータベース名は従来と同じため、同じブラウザ・同じGitHub Pages URLで更新すれば既存の登録データは引き継がれます。
- 既存データはJPY・換算レート1として扱います。
- 円換算レートは自動取得ではなく手入力です。支出した時点のレートを入力してください。
- 精算対象は、除外チェックのないデータです。参加者は「設定」の支払い者・参加者欄で登録してください（最大3人）。
- 重要なデータは定期的にJSONバックアップしてください。
